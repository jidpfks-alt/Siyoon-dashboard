📱 태블릿에서 여는 방법

🌐 인터넷 주소로 열기: https://jidpfks-alt.github.io/Siyoon-dashboard/
Chrome 주소창에 이 주소를 넣으면 파일 없이 바로 열려요. 열어 둔 뒤 ⋮ → 홈 화면에 추가를 해 두면 아이콘 한 번으로 열 수 있어요.

  1. 이 HTML 파일을 태블릿으로 보내요 (카카오톡 ‘나에게 보내기’ 후 저장, USB, 또는 구글 드라이브).
  2. 파일 관리자에서 파일을 눌러 Chrome으로 열어요.
  3. Chrome 오른쪽 위 ⋮ → 홈 화면에 추가를 해 두면 아이콘 한 번으로 열 수 있어요. (안 보이면 북마크로 저장해도 좋아요)
  4. 거실 거치대에 세우고, 여기서 화면 꺼짐 방지와 전체화면을 켜 두면 끝!

인터넷이 없어도 루틴·도장·준비물은 모두 동작해요. 날씨만 인터넷이 필요하고, 마지막으로 받은 날씨를 저장해 두었다가 보여 줘요.
