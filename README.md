# 시윤이의 포켓몬 저녁 루틴 대시보드

아이의 저녁 루틴(도장), 오늘의 한마디, 요일별 준비물, 동탄 날씨를 한 화면에 보여 주는 태블릿용 페이지입니다.
루틴·도장 기록은 브라우저 localStorage에만 저장되고 서버로 보내지 않습니다.

- 열기: https://jidpfks-alt.github.io/siyoon-dashboard/
- 원본 파일: `downloads/siyoon_evening_dashboard.html` (오프라인용, file:// 로 열어도 동작)
- 화면 꺼짐 방지: Screen Wake Lock API + 무음 루프 영상(NoSleep) 이중 방식
